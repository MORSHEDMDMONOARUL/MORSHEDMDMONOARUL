## Highlighted Projects

- **[ExamShield](https://github.com/MORSHEDMDMONOARUL/ExamShield)** — 16-camera AI exam proctoring system combining YOLOv8 detection with ESP32 edge hardware for real-time, on-premise monitoring.
- **[PQC-Lattice-Sandbox](https://github.com/MORSHEDMDMONOARUL/PQC-Lattice-Sandbox-ML-KEM-Kyber-Architecture-)** — Zero-dependency implementation of FIPS 203 ML-KEM (Kyber), built from the standard as a study of lattice-based post-quantum cryptography.
- **[Prompt-Studio](https://github.com/MORSHEDMDMONOARUL/Prompt-Studio)** — Prompt engineering workbench for building, testing, and comparing prompts against NVIDIA NIM inference endpoints.
- **[PDF Quiz Generator](https://github.com/MORSHEDMDMONOARUL/PDF_Quiz_Generator)** — Flask and LLM application that turns any document into a summary, a generated quiz, and a chat interface.
